ScatterPlotBar news and updates

Updates collected from the current live news page, rebuilt into a local static page instead of a redirect.

Several updates to Scatter Plot Bar App

The live page notes that the app can display significance levels as p values or asterisks together with brackets indicating compared columns or boxes. It also mentions support for exporting plots as PDF, TIFF, SVG, EPS, and PNG.

The same entry describes Scatter Plot Bar as a free online dot plot generator that can be combined with bars, columns, crossbars, boxplots, violin plots, heatmaps, and Excel-style line plots with standard deviations.

Molarity and Volume Calculator App

The calculator update describes an app for calculating the volume required to reach a target concentration based on molecular mass in Daltons. A second tab calculates molarity from mass and volume.

Scatter Plot Bar update with heatmap functionality

The news page states that heatmap support was added to the main Scatter Plot Bar app for uses such as gene expression analysis and activity visualisation over time.

New Web App for Analysing Calcium Imaging Time-Lapse Series

The live update presents the calcium imaging tool as a demo app that can analyse only several frames on the server and points larger-series users to the GitHub code path.

New Web App for Generating Correlation Heatmaps

The correlation heatmap entry highlights Pearson correlation heatmaps, counting correlating pairs, and an optional detrending workflow where negative values are excluded from the analysis.

Custom colors, stacked charts, and grouped graphs

The news page also covers user-defined datapoint colors, stacked columns and percent stacked barplots, and grouped columns, violin plots, boxplots, and crossbars combined with dot plots.
