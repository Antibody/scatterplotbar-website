Generation of Correlation Heatmaps Online

The instructions explain that detrending can produce negative values, and the app converts those negatives to NaN values before continuing.

br <- 50
break.points <- seq(from = br, to = dim(dat2)[1], by = br)
dat3 <- dat2
for (i in 1:dim(dat2)[2]) {
  dat3[, i] <- detrend(dat2[, i], bp = break.points)
}
dat3[, 1] <- dat2[, 1]
